## 변경

1. 자유단의 평균 위·아래 수축을 약 25% 축소했다. 상하 비대칭과 옆 방향 이동도 완화하면서 힌지 위치와 기울기 반응은 유지한다.
2. 가장 강한 Gaussian 반경은 약 13% 낮췄다. 가벼운 확산과 넓은 색 확산이 겹치는 범위를 조절해 선명한 글자가 흐린 영상 위에 남는 느낌을 줄인다. 전역 흰색 필터나 추가 광택은 넣지 않는다.
3. 기존 검은 경계는 Gaussian 합성 이후 전체 결과 위에 그려졌다. 이를 원본 평면 쪽으로 옮겨 경계의 어두움과 콘텐츠 색이 함께 확산되게 했다. 후처리 검은 경계가 퍼진 색을 다시 끊지 않는다. 경계 폭은 짧은 변의 최대 3.5%에서 5%로 넓혔다.
4. 평면 음영과 확산 음영을 낮춰 중간 색이 덜 탁해지게 했다. 두 Gaussian 층 구성과 축소 중간 버퍼는 그대로 사용한다.

HAL 각도 수신, HingeProgress, AngleSmoother, FoldService, 고정 패널 매핑·프레임 수명·입력 경로의 소스 해시는 변경 전과 같다. 근거: `measurements/renderer-v36/continuity-check.json`.

## 검증 상태

빌드·Java 테스트 57개·Lint 통과(기존 경고, 오류 없음). 실기 HardwareBufferRenderer에서 패널·렌더 방식별 288회씩 비교했다. 최적화 경로의 중앙값은 외부 7.32ms, 내부 8.07ms이고 p95는 각각 11.14ms, 12.07ms였다. 같은 턴에서 측정한 기존 버전은 중앙값 외부 6.86ms, 내부 7.88ms였다. 전환 애니메이션 전체 FPS가 아니라 생성된 입력을 그린 후 GPU 완료 fence까지의 분리 측정이며, 열·실행 순서 등의 영향은 남는다.

원본 해상도 Gaussian 대비 최적화 출력의 최대 평균 RGB 차이는 약 2.11/255였고, 선명한 표시 끝점과 내부 고정 면의 비교 표본은 동일했다. 흰색 입력의 네 경계 단면에서는 87–113개 밝기 단계와 픽셀당 최대 2.67–4.00/255의 변화가 관찰됐다. 경계 외부 8px가 검어야 한다는 이전 검증은 이번 의도적인 색 확산과 충돌하므로, 경계 폭 하나 바깥의 어두운 영역부터 콘텐츠 안쪽까지 스캔하도록 바꿨다. 원래의 밝기 점프·끝점·정지 면 검사 기준은 유지했다.
